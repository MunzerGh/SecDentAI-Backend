# 🦷 SecDentAI - Backend API

الخلفية البرمجية (Backend RESTful API) لمشروع **SecDentAI** — نظام إدارة عيادات الأسنان الذكية والمساعد المعتمد على الذكاء الاصطناعي.

---

## 🌟 أهم المميزات (Features)

* 🔐 **نظام مصادقة آمن (Authentication):** تسجيل الدخول وإدارة الجلسات باستخدام **JWT** وكلمات المرور المشفرة.
* 👨‍⚕️ **إدارة الملف الشخصي والإعدادات:** تخصيص بيانات الطبيب، رفع الصور الشخصية، وضبط إعدادات العيادة ولغة التطبيق.
* 📅 **إدارة المواعيد والمرضى:** تنظيم جداول الحجز والمواعيد والحالات الطارئة.
* 🤖 **تكامل مع بوت التلغرام (Telegram Bot):** استقبال طلبات الحجز واستفسارات المرضى التلقائية عبر التلغرام.
* 🦷 **الذكاء الاصطناعي وتحليل الأشعة:** الربط مع نموذج **YOLOv8** المخصص لكشف تسوس الأسنان وتحليل الصور الطبية.
* 🌐 **التكامل مع خدمات Google:** دعم تسجيل الدخول ومزامنة التقويم عبر Google OAuth & Calendar API.

---

## 🛠️ التقنيات المستخدمة (Tech Stack)

* **البيئة المعتمدة:** Node.js (Express.js)
* **قاعدة البيانات:** MySQL (باستخدام مكتبة `mysql2/promise`)
* **الأمان والمصادقة:** JSON Web Tokens (JWT)
* **إدارة المرفقات والصور:** Multer
* **الذكاء الاصطناعي والبوتات:** Python (YOLOv8, OpenCV), Telegram Bot API, Google Gemini API
